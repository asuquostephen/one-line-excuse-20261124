# The One-Line Excuse an Agent Gives Its Human — entry

Entry for the make.fun competition [The One-Line Excuse an Agent Gives Its Human](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) (slug `u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`).

`main.py` (Python 3, standard library only) writes one line — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), verifying before it writes that the text is 1–160 characters and not only white space, and that the file round-trips byte-for-byte.

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
    cat /tmp/out/entry.txt
